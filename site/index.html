demojify-sanitize
Install Use CLI Safety Docs

Strip the emoji clutter from AI output, user content, and your repository.

demojify-sanitize is a dependency-free Go library and CLI that detects emoji, removes them or swaps them for readable text such as [PASS], and tidies the whitespace they leave behind. Use it to post-process agent responses, sanitize submitted text, or fail a CI build when emoji creep into source and docs.

Small, predictable, and safe to run on anything

Pure standard library, no go.sum, and defaults that never silently do nothing.

Remove or substitute

Sanitize strips emoji; Replace maps 280 built-in emoji to text tokens and strips the rest. Custom maps are supported.

Script-aware

Keeps the Zero Width Joiner and variation selectors that shape Indic, CJK, and math text, while still removing every emoji.

Whitespace that stays put

Collapses redundant spaces and blank lines while preserving indentation, gofmt alignment, and CRLF line endings.

Streams, JSON, and trees

SanitizeReader for LLM streams, SanitizeJSON for string values only, and ScanDir / FixDir for whole repositories.

Install

Add the library to a module. The v1 import path has no /v1 suffix.

go get github.com/nicholashoule/demojify-sanitize@v1.2.0

Install the CLI, or run it once without installing:

go install github.com/nicholashoule/demojify-sanitize/cmd/demojify@v1.2.0
go run github.com/nicholashoule/demojify-sanitize/cmd/demojify@v1.2.0 -root .

Zero dependencies, Go 1.24 or newer

Everything is built on the standard library, so there is nothing else to fetch or audit. CI tests Go 1.24, 1.25, and the latest release on Linux, macOS, and Windows.

Use

Start from the safe presets. SanitizeSafe always removes emoji, keeps script joiners, and leaves whitespace alone.

import demojify "github.com/nicholashoule/demojify-sanitize"

clean := demojify.SanitizeSafe(aiResponse)

// Also collapse redundant whitespace.
opts := demojify.SafeOptions()
opts.NormalizeWhitespace = true
clean = demojify.Sanitize(text, opts)

// Substitute instead of strip.
clean = demojify.Replace(text, demojify.DefaultReplacements())

// Gate user input.
if demojify.ContainsEmojiWith(input, demojify.SafeOptions()) {
	return errEmojiNotAllowed
}

Whole repositories

cfg := demojify.SafeScanConfig()
findings, err := demojify.ScanDir(cfg)   // audit
fixed, _, err := demojify.FixDir(".", cfg) // audit and rewrite
FunctionPurpose
SanitizeSafeRecommended entry point: remove emoji, keep script joiners.
SanitizeConfigurable pipeline: removal, then whitespace normalization.
ReplaceMap emoji to text tokens; strip anything unmapped.
SanitizeReportCleaned text plus emoji removed and bytes saved.
SanitizeReaderLine-by-line streaming, lines up to 1 MiB.
SanitizeJSONClean string values; keys, numbers, and precision untouched.
ScanDir, FixDirWalk a tree, report per-file findings, and optionally write back.

Every function and option is documented on pkg.go.dev.

CLI

demojify audits a directory tree and reports every occurrence with file, line, and column. It exits 1 when it finds emoji, so it works as a CI gate or pre-commit hook.

demojify -root .                         # audit only; nothing changes
demojify -root . -exts .go,.md           # limit to these extensions
demojify -root . -fix                    # strip emoji in place
demojify -root . -sub                    # substitute text tokens in place
demojify -root . -sub -normalize         # substitute and tidy whitespace
demojify -root . -skip dist,build -json  # machine-readable findings
demojify -version

See the CLI reference for every flag and exit code, CI integration for GitHub Actions and GitLab CI, and git hooks for blocking emoji at commit time.

Safety

A zero Options passes text through unchanged, as v1 promises, so a forgotten field can silently turn sanitizing off. SafeOptions, SanitizeSafe, and SafeScanConfig leave nothing to forget: they always remove emoji.

File writes go through a same-directory temp file and rename, preserving permissions. A file edited after it was read is left alone and reported with ErrFileChanged. Scans skip binary files and the safe preset caps file size; FixDir never writes through a path or symlink that resolves outside its root. SECURITY.md says how to report a vulnerability.
